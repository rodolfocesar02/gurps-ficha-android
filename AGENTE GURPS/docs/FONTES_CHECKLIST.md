# Checklist de Fontes - AGENTE GURPS

Use este checklist para cada livro/material adicionado em `AGENTE GURPS/sources`.

## Metadados minimos
1. Titulo do material.
2. Idioma (`pt` ou `en`).
3. Tipo (`pdf`, `txt`, `md`, `json`).
4. Versao/edicao.
5. Permissao de uso no projeto (`sim`/`nao`).

## Qualidade de ingestao
1. OCR legivel (sem texto quebrado em excesso).
2. Paginas numeradas de forma consistente.
3. Sem duplicatas evidentes do mesmo conteudo.
4. Nome de arquivo padronizado.

## Regra de resposta
1. Mesmo com fonte em ingles, saida final em portugues.
2. Citar fonte e pagina quando possivel.
3. Se traducao for aplicada, indicar que foi traducao.
